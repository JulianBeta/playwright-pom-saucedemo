# BUG-003: Add to cart / Remove silently fail for half the products

|                    |                                                                          |
| ------------------ | ------------------------------------------------------------------------ |
| **Severity**       | High                                                                     |
| **Type**           | Functional                                                               |
| **Affected users** | problem_user, error_user                                                 |
| **Environment**    | https://www.saucedemo.com · Chromium, Firefox, WebKit · found 2026-11-02 |
| **Status**         | Open — tracked by an expected-failure test                               |

## Steps to reproduce

1. Log in as `problem_user` (or `error_user`).
2. Click **Add to cart** on all six products.

## Expected

Cart badge shows 6 and every button changes to **Remove**.

## Actual

Badge stops at 3. Add to cart does nothing for Bolt T-Shirt, Fleece Jacket and Test.allTheThings() T-Shirt; for `problem_user` **Remove** also does nothing.

## Automated test

features/known-bugs/problem-user.feature and error-user.feature → _Every product can be added to the cart_
