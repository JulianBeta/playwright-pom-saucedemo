# BUG-005: Last Name field does not accept typing

|                    |                                                                          |
| ------------------ | ------------------------------------------------------------------------ |
| **Severity**       | Critical                                                                 |
| **Type**           | Functional                                                               |
| **Affected users** | problem_user                                                             |
| **Environment**    | https://www.saucedemo.com · Chromium, Firefox, WebKit · found 2026-11-02 |
| **Status**         | Open — tracked by an expected-failure test                               |

## Steps to reproduce

1. Log in as `problem_user`, add a product and open checkout.
2. Type into **Last Name**.

## Expected

The typed text appears in Last Name.

## Actual

Last Name stays empty (keystrokes end up in First Name), so the customer can never pass the _Last Name is required_ validation.

## Automated test

features/known-bugs/problem-user.feature → _The last name field accepts input_
