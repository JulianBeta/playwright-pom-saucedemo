# BUG-006: Checkout continues without a last name

|                    |                                                                          |
| ------------------ | ------------------------------------------------------------------------ |
| **Severity**       | High                                                                     |
| **Type**           | Validation                                                               |
| **Affected users** | error_user                                                               |
| **Environment**    | https://www.saucedemo.com · Chromium, Firefox, WebKit · found 2026-11-02 |
| **Status**         | Open — tracked by an expected-failure test                               |

## Steps to reproduce

1. Log in as `error_user`, add a product and open checkout.
2. Fill First Name and Postal Code, leave Last Name empty, click **Continue**.

## Expected

Error _Last Name is required_; the user stays on step one.

## Actual

The user moves on to the overview with no last name.
