# BUG-007: Sorting throws an error alert

|                    |                                                                          |
| ------------------ | ------------------------------------------------------------------------ |
| **Severity**       | Medium                                                                   |
| **Type**           | Functional / Error handling                                              |
| **Affected users** | error_user                                                               |
| **Environment**    | https://www.saucedemo.com · Chromium, Firefox, WebKit · found 2026-11-02 |
| **Status**         | Open — tracked by an expected-failure test                               |

## Steps to reproduce

1. Log in as `error_user`.
2. Choose any sort option.

## Expected

Products are re-ordered.

## Actual

A browser alert says _Sorting is broken! This error has been reported to Backtrace._ and the order does not change.

## Automated test

features/known-bugs/error-user.feature → _Sorting works without an error alert_
