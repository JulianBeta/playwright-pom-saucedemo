# BUG-008: Finish does not complete the order

|                    |                                                                          |
| ------------------ | ------------------------------------------------------------------------ |
| **Severity**       | Critical                                                                 |
| **Type**           | Functional                                                               |
| **Affected users** | error_user                                                               |
| **Environment**    | https://www.saucedemo.com · Chromium, Firefox, WebKit · found 2026-11-02 |
| **Status**         | Open — tracked by an expected-failure test                               |

## Steps to reproduce

1. Log in as `error_user`, add a product, go through checkout to the overview.
2. Click **Finish**.

## Expected

The confirmation page shows _Thank you for your order!_ and the cart is emptied.

## Actual

Nothing happens; the user stays on the overview and the cart keeps its items.

## Automated test

features/known-bugs/error-user.feature → _Finishing the order completes the purchase_
