# BUG-011: An order can be placed with an empty cart

|                    |                                                                          |
| ------------------ | ------------------------------------------------------------------------ |
| **Severity**       | High                                                                     |
| **Type**           | Business rule                                                            |
| **Affected users** | all users                                                                |
| **Environment**    | https://www.saucedemo.com · Chromium, Firefox, WebKit · found 2026-11-02 |
| **Status**         | Open — tracked by an expected-failure test                               |

## Steps to reproduce

1. Log in as `standard_user` with an empty cart.
2. Open the cart and click **Checkout**, then fill in the customer information.

## Expected

Checkout is disabled (or explains the cart is empty).

## Actual

Checkout proceeds to the overview showing a **$0.00** total, ready to be finished.

## Automated test

features/known-bugs/standard-user.feature → _Checkout cannot start with an empty cart_
