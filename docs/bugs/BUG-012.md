# BUG-012: Reset App State leaves product buttons in the Remove state

|                    |                                                                          |
| ------------------ | ------------------------------------------------------------------------ |
| **Severity**       | Low                                                                      |
| **Type**           | Functional / State                                                       |
| **Affected users** | all users                                                                |
| **Environment**    | https://www.saucedemo.com · Chromium, Firefox, WebKit · found 2026-11-02 |
| **Status**         | Open — tracked by an expected-failure test                               |

## Steps to reproduce

1. Log in as `standard_user`, add Sauce Labs Backpack.
2. Open the menu → **Reset App State**.

## Expected

Cart is emptied and the button goes back to **Add to cart**.

## Actual

The badge disappears, but the button still says **Remove**.

## Automated test

features/known-bugs/standard-user.feature → _Reset App State also resets the product buttons_
