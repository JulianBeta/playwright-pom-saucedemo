# BUG-013: Products page can flash after logout + Back (intermittent)

|                    |                                                                          |
| ------------------ | ------------------------------------------------------------------------ |
| **Severity**       | Medium                                                                   |
| **Type**           | Security / Session                                                       |
| **Affected users** | all users                                                                |
| **Environment**    | https://www.saucedemo.com · Chromium, Firefox, WebKit · found 2026-11-02 |
| **Status**         | Intermittent — monitored                                                 |

## Steps to reproduce

1. Log in, open the products page.
2. Log out, then press the browser **Back** button.

## Expected

The login page is shown; no protected content is rendered.

## Actual

During exploration the products page was rendered for under a second before the redirect to login. **Not reliably reproducible**: the automated check (which waits for the final state) passes in all browsers.

## Automated test

features/auth/access-control.feature → _The Back button after logout does not reveal protected pages_ (regression guard; passes)
