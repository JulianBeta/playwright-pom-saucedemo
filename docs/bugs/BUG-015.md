# BUG-015: Slider auto-rotation cannot be paused (WCAG 2.2.2)

|                    |                                                                          |
| ------------------ | ------------------------------------------------------------------------ |
| **Severity**       | Medium                                                                   |
| **Type**           | Accessibility                                                            |
| **Affected users** | all users                                                                |
| **Environment**    | https://www.saucedemo.com · Chromium, Firefox, WebKit · found 2026-11-02 |
| **Status**         | Open — tracked by an expected-failure test                               |

## Steps to reproduce

1. Menu → Dynamic Catalog → **Slider**.
2. Hover over (or focus) the slider and wait.

## Expected

Auto-rotation pauses on hover/focus or there is a pause control (WCAG 2.2.2 _Pause, Stop, Hide_).

## Actual

Slides keep advancing every ~2 s with no way to stop them.

## Automated test

features/dynamic-catalog/slider.feature → _Auto-rotation pauses while the pointer is over the slider_
